## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or Bun
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/Jushita12/Jushita-Pediredla-E-Portfolio-.git
cd Jushita-Pediredla-E-Portfolio-

# Install dependencies
npm install
# or
bun install

# Start development server
npm run dev
# or
bun run dev
```

The portfolio will be available at `http://localhost:8080/`

### Building for Production

```bash
npm run build
# or
bun run build
```
